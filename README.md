# cjajunior.github.io

Portfólio de Claudio Junior Alicati, desenvolvedor web: https://cjajunior.github.io

Projetos em destaque:

- [Atrium](https://atrium-client-portal.vercel.app/): portal de clientes com controle de acesso por Row Level Security ([código](https://github.com/cjajunior/atrium))
- [Leon Barber Shop](https://leon-barbearia.vercel.app/): agendamento e painel do dono para uma barbearia de Campo Limpo Paulista
- [ClientFlow](https://clientflow-pi-gray.vercel.app/): gestão de clientes, faturas e fluxo de caixa

O site é uma única página em HTML, CSS e JavaScript, sem dependências. O texto usa a fonte Atkinson Hyperlegible Next, do Braille Institute, carregada pelo Google Fonts sob a licença SIL Open Font License.
